# 项目待办整理器

## 目标

提供一个完全在本机使用的轻量工具，用来整理项目工作清单。用户可以粘贴或导入 Markdown 待办，按原有分组查看，并标记每项已完成或未完成。

## 成功条件

使用真实 Markdown 样例验证：

1. 粘贴或导入后能看到分组、待办内容及已完成/未完成状态。
2. 可以切换单项完成状态，并筛选未完成事项。
3. 刷新页面后，内容、分组和勾选状态仍保留。
4. 可以分别导出 Markdown 和 CSV。
5. 空输入和不含待办的普通行有明确处理方式。
6. 含 HTML 特殊字符的待办按普通文本显示，不被解释为 HTML。
7. 导入文件仅作为输入读取；原文件不被修改，全部清单数据留在本机。

## 边界

- 不联网，不上传导入内容。
- 不改写用户选择的原文件。
- 保持清单文本为文本；不得执行其中的标记或脚本。
- 只实现本次待办整理验例，不新增账号、云同步或项目管理后台。

本文件是需求基线，不代表功能已实现或验收通过。
