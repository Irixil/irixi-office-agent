# Current product scope

The current product helps an individual discuss an idea, explicitly begin work, create or modify a real local project, inspect a usable result, and continue later. A project may contain multiple conversations sharing its files and relevant history.

The conversation workbench includes project organization, a folder chooser, per-turn model selection, message copying/quoting/editing, references and branches, actual tool activity, scoped parallel helpers and editable memory, clear progress, stop/recovery handling, and a macOS shell.

Ordinary work does not require a fixed project setup form or repeated plan approvals. Necessary questions and new permissions are handled in context. OmO is the sole harness; DZ supplies internal continuity rules mapped to product storage.

The October 30 local deliveries include backend connection support, a product-developed focus-record editor, and the owner-reviewed desk-sleep update. See [current progress](../../STAGE_STATUS.md), [examples](../showcase.md), and [setup](../getting-started.md). The public tree is source-only and excludes original runtime data and installed binaries.

The official OpenAI API Key file route is available with its documented tool scope. DeepSeek live validation is deferred. Public web sharing remains outside this source release. Earlier requirements and example implementations are historical rather than the current entry workflow.
