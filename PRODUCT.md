# iRIXI Office Personal Agent

A conversation-first desktop personal agent for discussing, making, modifying, and continuing real local projects. The office is an interface to that work rather than a restriction on task categories.

## Current product

- Multiple conversations per project, with user-selected file locations.
- Real file and command tools, functional checks, and runnable outcomes.
- Editable messages, quotes, references, branches, and local deep links.
- Per-turn model selection, actual work activity, and read-only child agents.
- Stop, persistence, recovery, project-level write coordination, and existing-data protection.
- An interactive Victorian office and macOS application shell.

OmO is the sole current harness. The model and CLI connection are replaceable. DZ is the internal continuity method; developer project records and user task storage are separate.

The October 27 maintainer installation completed its engineering, system, independent, and installation checks. The public update is source-only. User adoption and new-machine installation are separate from that local acceptance.
